India-Retail-Sales-Data-Analysis (interactive Dashboard Cresting Using Power BI﻿)

🚀 Project Overview

An interactive Power BI dashboard built to analyze India’s retail and sales data (FY 2026 - Q1).
This project focuses on transforming raw data into meaningful insights using data visualization, DAX, and data modeling.

🎯 Objective

The goal of this project is to:

📈 Analyze sales performance and order trends
🛍️ Identify top-performing product categories
👥 Understand customer demographics (age, gender, occupation)
🌍 Evaluate state-wise sales distribution
💡 Enable data-driven business decisions
🖼️ Dashboard Preview
🏠 Retail Orders Dashboard
📊 Orders Analysis Dashboard
💰 Sales Dashboard
📑 Data Tables & DAX View

🔍 Insights
🧥 Clothing & Food categories dominate sales
👥 Age group 26–35 contributes the highest orders
📍 Top States: Uttar Pradesh, Karnataka, Delhi

📦 Mid-range products show consistent demand
